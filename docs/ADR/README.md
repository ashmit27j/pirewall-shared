# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) that document important architectural decisions made during the development of pirewall.

## What are ADRs?

Architecture Decision Records are documents that capture important architectural decisions made along with their context and consequences. They help ensure that the architecture remains understandable and maintainable over time.

## Format

Each ADR should be a separate markdown file following this format:

- Title: A descriptive title
- Date: The date of the decision
- Status: Accepted, Rejected, Superseded, etc.
- Context: What led to this decision
- Decision: What was decided
- Consequences: What follows as a result of this decision

## Template

```markdown
# [Title]

## Date

[Date of decision]

## Status

[Status - e.g., Accepted, Rejected, Superseded]

## Context

[What is the issue that we're seeing that is addressed by this decision]

## Decision

[What is the change that we're proposing or doing]

## Consequences

[What becomes easier or harder to do because of this decision]
```
