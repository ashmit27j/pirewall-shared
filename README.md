# pirewall-shared

This repository contains shared components for the pirewall project.

## Project Structure

- `shared/` - Shared modules and utilities
- `docs/` - Documentation files
- `tests/` - Test files
- `examples/` - Example usage files

## Getting Started

To use this package, install it in development mode:

```bash
pip install -e .
```
